# React + TypeScript + Vite

## Cha-Movie

A modern React web application for browsing movies. Built with Vite, TypeScript, Tailwind CSS, and React Router. This app integrates Axios for API requests and uses Tailwind for styling.

### Features

- ⚛️ React 19 with Hooks  
- ⚡ Fast development and builds with Vite  
- 🎨 Styled using Tailwind CSS  
- 🔄 Routing with React Router  
- 🌐 Axios for API requests  
- 🧑‍💻 Linting with ESLint  
- 🛠️ TypeScript for type safety  

### Requirements

- Node.js (v16 or higher recommended)

### Getting Started

## Install dependencies

npm install

## Run the development server

npm run dev
